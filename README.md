# InfusApp — CS50P Final Project

A web app that helps nurses automate infusion monitoring and documentation. 
Click a button simultaneously with the drip rhythm to calculate infusion speed.
The application calculates the infusion duration and completion time automatically.

## Key Features

- User registration for nurses
- Patient and medication intake (name, medication, volume)
- Rhythm-based speed detection (tap button 3× with drip rhythm)
- Automatic infusion speed & completion time calculation
- Automated documentation (start & end times)
